Terminal 1 - START OLLAMA (AI Engine)
───────────────────────────────────────
Command:
  ollama serve

Wait for:
  listening on 127.0.0.1:11434

✅ Keep this running!

────────────────────────────────────────────────────────────────

Terminal 2 - START PYTHON BACKEND (API Server)
───────────────────────────────────────────────
Command:
  cd D:\ULTRON-OS\backend
  python main.py

Wait for:
  Running on http://127.0.0.1:5000

✅ Keep this running!

────────────────────────────────────────────────────────────────

Terminal 3 - START REACT FRONTEND (UI)
───────────────────────────────────────
Command:
  cd D:\ULTRON-OS\frontend
  npm run dev

Wait for:
  Local: http://localhost:5173/

✅ Keep this running!

════════════════════════════════════════════════════════════════
TROUBLESHOOTING
════════════════════════════════════════════════════════════════

Problem: "Port already in use"
Solution: 
  - Close existing instances
  - Or restart Windows

Problem: "Ollama connection failed"
Solution:
  - Make sure Terminal 1 is running
  - Check Ollama is installed

Problem: "No audio from microphone"
Solution:
  - Check Windows sound settings
  - Ensure microphone is default device

Problem: "Slow responses"
Solution:
  - First run of AI is slower
  - Subsequent responses faster
  - Normal behavior!
